# Лабораторная работа №5

## Особенности проекта

* **Динамическое управление DOM:** генерация карточек треков (`<li>`) в рантайме с помощью `document.createElement`, безопасное удаление узлов через `.remove()` и реактивное обновление текстовых узлов счетчиков.
* **Архитектура выборки элементов:** поиск узлов выстроен на связке нативных методов — `getElementById` для управляющих кнопок и полей ввода, `querySelector` для контейнеров и блока ошибок, а также `querySelectorAll` для пакетных операций со списком элементов.
* **Система переключения тем (Dark / Light):** смена оформления страницы по кнопке в шапке с динамической подменой набора CSS-переменных, контролем контрастности текста ($\ge 4.5:1$) и обновлением состояния доступности `aria-pressed`.
* **Управление видимостью интерфейса:** сворачивание и разворачивание блока плейлиста через переключение класса `.hidden` с синхронной актуализацией атрибута `aria-expanded` для вспомогательных технологий.


* **Интерактивные карточки треков:** каждый элемент списка снабжен чекбоксом «Избранное» с акцентной подсветкой рамки классом `.is-favorite` и отдельной кнопкой удаления композиции.


* **Отказоустойчивость и валидация:** защитная проверка существования DOM-узлов перед инициализацией слушателей событий, предотвращение пустого ввода и проверка хронометража регулярным выражением (`ММ:СС`) с выводом предупреждений в интерфейс.
* **Персистентность данных (localStorage):** сохранение массива треков, статусов избранного и выбранной темы в локальном хранилище браузера с автоматическим восстановлением структуры при событии `DOMContentLoaded`.

## Запуск

Откройте файл `index.html` в браузере или перейдите по ссылке опубликованного сайта на GitHub Pages.

## Проверка

HTML- и CSS-код успешно валидируются сервисами W3C, работа скриптов манипуляции DOM-деревом и синхронизация данных с `localStorage` протестированы в инструментах разработчика.
